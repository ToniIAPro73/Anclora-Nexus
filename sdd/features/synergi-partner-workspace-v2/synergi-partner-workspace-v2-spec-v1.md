# Spec v1

## Objetivo
Convertir `Synergi Workspace` en una superficie más útil para partners aprobados sin abandonar el modelo de acceso por token.

## Qué añade
- perfil operativo editable
- preferencias de tipos de oportunidad
- zonas prioritarias
- canales de contacto preferidos
- compromiso de respuesta
- feed de actividad del workspace

## Eventos trazados
- `workspace_activated`
- `profile_updated`
- `opportunity_submitted`
