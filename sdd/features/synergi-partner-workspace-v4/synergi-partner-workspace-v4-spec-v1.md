# Spec v1

## Objetivo
Hacer que `Synergi Workspace` no sea solo un canal de ida y vuelta, sino una superficie donde el partner entienda qué prioriza Anclora y cómo debe activar mejor la relación.

## Qué añade
- bloque `Prioridades sugeridas por Anclora`
- recomendaciones derivadas desde:
  - preferencias declaradas
  - zonas prioritarias
  - oportunidades compartidas pendientes o interesantes
- shell premium para portales externos
- diferenciación visual sutil entre `Partner` y `Data Lab`

## No añade
- nueva migración
- nuevo rol
- nueva capa de autenticación
