Implementar una operación local supervisada que:
- abra Telegram Web con Playwright
- reutilice perfil persistente
- permita al operador mostrar resultados de StateFox
- capture texto y enlaces observables
- guarde un artifact local reutilizable por el bridge
- adjunte handoff y validaciones mínimas de importabilidad
