# Feature Rule - ANCLORA-DLAB-001

- `Data Lab` vive como superficie externa-controlada del ecosistema, no como clon de `Nexus`.
- `Data Lab` debe reutilizar `MTIP` y observabilidad existente antes de crear una capa backend nueva.
- toda copy nueva debe pasar por i18n
- toda superficie nueva debe respetar contratos de `surface`, tipografia y formularios
- si hay datos live, deben mostrarse solo con acceso autenticado y aislamiento por tenant
