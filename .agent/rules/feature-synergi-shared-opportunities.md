# ANCLORA-SPW-003 · Synergi Shared Opportunities

- `Synergi` debe permitir compartir oportunidades curadas desde Anclora hacia partners ya aprobados.
- La capacidad vive en dos superficies coordinadas:
  - consola interna de Nexus para compartir
  - workspace externo del partner para responder
- Todo acceso externo sigue usando token controlado y sin exponer dashboard interno.
- Mantener contratos UI, i18n y fallbacks seguros en formularios, selects y cards.
- El estado minimo del ciclo es:
  - `shared`
  - `interested`
  - `declined`
  - `archived`
