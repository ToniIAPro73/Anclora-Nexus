# ANCLORA-SPW-001 · Synergi Partner Workspace

- El workspace de partner nace solo tras una admisión aceptada.
- El acceso v1 es controlado por `invite token`, no por auth externa completa.
- El portal debe permitir:
  - ver perfil aprobado
  - ver próximos pasos
  - ver recursos base
  - enviar oportunidades/referrals a Anclora
- Toda copy nueva debe pasar por i18n.
- Toda surface debe respetar los contratos UI de `surface-*`, `page-title`, `section-title` y estados sobrios.
