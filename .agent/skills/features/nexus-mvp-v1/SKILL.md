# Skill — Nexus MVP v1

## Lecturas obligatorias
1) `sdd/core/constitution-canonical.md`
2) `sdd/features/nexus-mvp-v1/nexus-mvp-v1-INDEX.md`

## Instrucciones
- Tratar el MVP como un recorte de superficie, no como una poda destructiva.
- Priorizar el flujo diario: sellers, buyers/leads, properties, tasks.
- Mantener `prospection-unified` solo como soporte operativo.
- Reutilizar i18n, temas y gramaticas visuales existentes.
- Cuando una feature quede fuera del MVP, ocultarla o despriorizarla antes que eliminarla.

## Stop rules
- No borrar features existentes.
- No romper contratos o rutas por simplificar la UI.
- No abrir rediseños globales no ligados al MVP.
