# Skill · Data Lab Selective Access

## Objetivo
Implementar acceso externo controlado a `Data Lab` mediante:
- solicitud pública
- revisión interna
- workspace externo tokenizado

## Flujo mínimo
1. contrato de datos y migración
2. endpoint público de solicitud
3. cola interna de revisión
4. workspace externo por token
5. validación en Nexus y `Private Estates`
