# Feature Prompt v1 — ANCLORA-NXMVP-001

Objetivo: implementar y mantener `nexus-mvp-v1` como una reduccion de superficie de producto centrada en captacion, seguimiento y conversion, sin eliminar capacidades existentes del repo.

## Inputs obligatorios
- `sdd/features/nexus-mvp-v1/nexus-mvp-v1-INDEX.md`
- `sdd/features/nexus-mvp-v1/nexus-mvp-v1-spec-v1.md`
- `.agent/rules/feature-nexus-mvp-v1.md`
- `.agent/rules/anclora-nexus.md`

## Entregables
1) Navegacion principal alineada con el MVP.
2) Modulos no-MVP preservados pero fuera del relato principal.
3) Compatibilidad mantenida con idiomas y temas existentes.
4) Cambios reversibles y trazables.

## Restricciones
- No borrar funcionalidades existentes.
- No romper rutas existentes salvo decision explicita.
- No convertir el trabajo en un rediseño visual global.
- Priorizar sellers, buyers/leads, properties, tasks y prospection ligera.
